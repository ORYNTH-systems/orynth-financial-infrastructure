# UAA Binding

## Canonical Owner
Unified Agency Architecture (UAA)

## Inherited Properties

- authority does not exist by default
- capability is not authority
- admissibility precedes authority
- authorization is attempt-specific
- authorization must be verified at the execution boundary
- replayed authorization is invalid
- indeterminate execution fails closed
- blocked execution produces no governed effect

## Financial Specialization

Financial Infrastructure applies these properties to financially consequential execution.

## Prohibited Redefinition

This repository SHALL NOT redefine generic authority creation, admissibility, or control-point semantics.

## F1-F8 Relationship

All F1-F8 execution authority derives through the inherited UAA boundary.
