# Related Repository Classification

## DIRECT-INHERITED

Owns canonical architecture or domain substrate directly inherited by Financial Infrastructure.

## EXECUTION-SUPPORT

Provides runtime, enforcement, execution-engine, adapter, or demonstration machinery
that supports financial execution but does not automatically own the financial primitive.

## DOMAIN-RELATED

Contains research or architecture potentially relevant to Financial Infrastructure
but is not a canonical finance dependency unless later promoted through explicit reconciliation.

## UNRESOLVED

Ownership or role has not yet been sufficiently established.

---

Relationship classification does not transfer canonical ownership.

Presence of copied or nested source does not establish ownership.

Git repository identity, canonical architectural lineage, and explicit binding records
take precedence over incidental filesystem location.
