# Financial Object Non-Equivalence Rules

The following relations are explicitly non-equivalent unless separately proven:

Ownership != Control

Control != Custody

Custody != Authority

Key Possession != Authority

Wallet Control != Authority

Authorization Artifact Possession != Current Admissibility

Prior Authorization != Current Authority

Consensus != Authority

Technical Finality != Governance Validity

Valid Smart Contract != Admissible Smart Contract Execution

Economic Balance Equivalence != Historical State Equivalence

Compensation != Reversal

Reversal != Erasure

Reconstruction != Restoration

Function Restoration != Continuity Restoration

Evidence != Authority

Measurement != Authority

Capability != Authority

These distinctions are normative architectural separations for subsequent FIN-ARCH and F1-F8 work.
