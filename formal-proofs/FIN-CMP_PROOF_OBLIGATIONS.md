# FIN-CMP — Canonical Proof Obligations

## Status

All obligations in this file begin OPEN.

No obligation is proved or discharged by FIN-ARCH-06.

---

## PO-FIN-CMP-001 — Compensation Is New Execution

**Invariant:** FIN-CMP-001

**Formal target:** Show that compensation is a new independently governed execution and cannot inherit authority automatically from the originating failure or requirement.

**Required premises:** Originating execution/effect; explicit compensation requirement; new authority reference; new admission result; compensation execution record.

**Counterexample condition:** Compensation executes solely because compensation was required or because the prior execution failed.

**Evidence requirement:** Compensation requirement record; independent authority/admission record; compensation execution trace; post-effect state evidence.

**Implementation requirement:** Reference runtime must model compensation as a new event with independent authority/admission.

**Verification requirement:** Unauthorized compensation, partial compensation, and valid compensation cases.

**Dependencies:** Financial specialization

**First major paper:** F1

**Discharge state:** OPEN
