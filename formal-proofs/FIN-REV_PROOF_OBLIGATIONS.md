# FIN-REV — Canonical Proof Obligations

## Status

All obligations in this file begin OPEN.

No obligation is proved or discharged by FIN-ARCH-06.

---

## PO-FIN-REV-001 — Reversal Is New Execution

**Invariant:** FIN-REV-001

**Formal target:** Show that reversal is a new independently governed execution and cannot erase originating history or imply historical equivalence.

**Required premises:** Originating execution/effect; reversal requirement; new authority reference; new admission result; reversal execution record.

**Counterexample condition:** Reversal executes without independent admission or causes the original execution/effect to disappear from historical representation.

**Evidence requirement:** Reversal requirement record; independent authority/admission record; reversal trace; preserved originating history.

**Implementation requirement:** Reference runtime must model reversal as a new event with independent authority/admission.

**Verification requirement:** Unauthorized reversal, partial reversal, historical-preservation cases.

**Dependencies:** Financial specialization

**First major paper:** F1

**Discharge state:** OPEN
