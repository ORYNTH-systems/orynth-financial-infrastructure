# FIN-EFF — Canonical Proof Obligations

## Status

All obligations in this file begin OPEN.

No obligation is proved or discharged by FIN-ARCH-06.

## PO-FIN-EFF-001 — No Effect Is Distinct From Partial Effect

**Invariant:** FIN-EFF-001

**Formal target:** Show that economic-effect classes remain observably distinct and that later remediation does not erase earlier effect history.

**Required premises:** Before-state; observed after-state; intended effect; actual effect; evidence lineage.

**Counterexample condition:** Two materially distinct effect classes collapse to the same representation or earlier effect history is lost after remediation.

**Evidence requirement:** Before/after state evidence; effect classification record; resource mutation trace; historical lineage.

**Implementation requirement:** Reference runtime must represent distinct effect states and preserve effect history.

**Verification requirement:** No-effect/partial/completed/compensating/reversal effect classification tests.

**Dependencies:** Financial specialization

**First major paper:** F1

**Discharge state:** OPEN
