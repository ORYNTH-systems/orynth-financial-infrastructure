# FIN-ADM — Canonical Proof Obligations

## Status

All obligations in this file begin OPEN.

No obligation is proved or discharged by FIN-ARCH-06.

---

## PO-FIN-ADM-001 — Authorization Does Not Imply Admission

**Invariant:** FIN-ADM-001

**Formal target:** Show that current admission is independently determined at the required execution boundary and cannot be inferred solely from prior authorization or transition definition.

**Required premises:** Defined transition; current state; applicable authority; policy; dependencies; resource state; jurisdiction state where applicable.

**Counterexample condition:** A transition enters execution without a valid contemporaneous admission determination.

**Evidence requirement:** Admission decision; current-state snapshot; applicable constraints; block evidence for failed/indeterminate admission.

**Implementation requirement:** Reference runtime must expose explicit admission decision before consequential transition.

**Verification requirement:** Admission pass/fail/indeterminate cases at execution time.

**Dependencies:** UAA/DEI

**First major paper:** FOUNDATION

**Discharge state:** OPEN
