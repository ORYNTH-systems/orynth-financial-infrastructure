# FIN-JUR — Canonical Proof Obligations

## Status

All obligations in this file begin OPEN.

## PO-FIN-JUR-001 — Jurisdiction Is Execution Relevant State

**Invariant:** FIN-JUR-001

**Formal target:** Show that execution-relevant jurisdiction is current, explicit, non-silently-collapsed, and cannot implicitly expand authority.

**Required premises:** Jurisdiction state; execution time; actor/resource scope; governing constraints; conflict state if applicable.

**Counterexample condition:** Execution proceeds under stale, unknown, silently conflicting, or authority-expanding jurisdictional assumptions.

**Evidence requirement:** Current jurisdiction observation; applicable constraints; conflict evidence; cross-boundary transition evidence.

**Implementation requirement:** Runtime must evaluate jurisdiction state where applicable and fail closed on required indeterminacy.

**Verification requirement:** Jurisdiction drift, conflict, unknown applicability, and cross-border cases.

**Dependencies:** Financial specialization

**First major paper:** F7

**Discharge state:** OPEN
