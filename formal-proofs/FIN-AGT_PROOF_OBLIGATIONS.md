# FIN-AGT — Canonical Proof Obligations

## Status

All obligations in this file begin OPEN.

No obligation is proved or discharged by FIN-ARCH-06.

## PO-FIN-AGT-001 — Agent Capability Is Not Economic Authority

**Invariant:** FIN-AGT-001

**Formal target:** Show that autonomous financial execution remains bound to valid external authority, principal resolution, delegation attenuation, and current admitted intent.

**Required premises:** Agent identity; principal reference; delegation chain; authorized intent; current action; scope; current authority.

**Counterexample condition:** An agent executes outside valid principal/delegation/scope/current-intent authority or self-authorizes.

**Evidence requirement:** Principal binding; delegation chain; agent identity; intent binding; current action; admission decision.

**Implementation requirement:** Agent execution must resolve principal, delegation, current intent, scope, and admission.

**Verification requirement:** Self-authorization, scope drift, principal loss, delegation attenuation, intent drift cases.

**Dependencies:** UAA

**First major paper:** F8

**Discharge state:** OPEN
