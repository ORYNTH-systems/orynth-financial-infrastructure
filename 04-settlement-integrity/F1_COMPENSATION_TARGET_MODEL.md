# F1 — Compensation Target Model

## Purpose

Compensation requires an explicit target.

The target is not automatically identical to the original intended state.

---

## Compensation Target

Define:

T_C =
(
    target_dimensions,
    target_values,
    required_dimensions,
    permitted_substitutions,
    tolerated_residuals,
    prohibited_new_effects,
    authority_constraints,
    evidence_requirements
)

---

## Target Classes

### RESTORATIVE_TARGET

Attempts to return selected current-state dimensions to a specified prior value or relation.

Does not erase history.

### EQUIVALENCE_TARGET

Targets an explicitly defined economic-equivalence projection rather than full state identity.

### SUBSTITUTE_REMEDY_TARGET

Permits one economic dimension to remediate divergence in another dimension where explicitly authorized.

Example:

cash compensation for an unavailable asset.

This substitution must be explicit.

### OBLIGATION_TARGET

Targets discharge or modification of defined obligations.

### CONTAINMENT_TARGET

Targets stable containment rather than restoration.

Used where further remediation would be unsafe, unavailable, or inadmissible.

---

## Target Validity

A compensation target is not valid merely because it is mathematically definable.

Target validity may depend on:

- current authority,
- current resource availability,
- scope,
- policy,
- counterparty status,
- settlement state,
- jurisdiction,
- external constraints.

---

## Target Change

If current state changes materially before compensation executes, T_C may require revalidation.

Prior compensation target validity does not imply current compensation target validity.
