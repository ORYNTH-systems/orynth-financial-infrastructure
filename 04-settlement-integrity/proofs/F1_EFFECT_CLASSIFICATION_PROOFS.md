# F1 Effect Classification Proofs

## F1-THM-EFF-001 — Partial Effect Classification

### Statement

If:

K = M*

and:

empty proper-subset M_econ proper-subset M*

then:

C_F1 = PARTIAL.

### Derivation

FIN-F1-02 defines PARTIAL exactly where:

1. occurrence knowledge is complete over all material intended mutations; and
2. the economically recognized mutation set is non-empty; and
3. the economically recognized mutation set is not equal to the complete intended
   mutation set.

Therefore:

K = M*

and:

empty proper-subset M_econ proper-subset M*

satisfy the defining condition of PARTIAL.

Hence:

C_F1 = PARTIAL.

### Result

PROVED

### Evidence Type

DEFINITIONAL-DERIVATION

## F1-THM-EFF-004 — Material Knowledge Deficit

### Statement

If material mutation occurrence status remains unresolved:

K != M*

then a determinate NO-EFFECT / PARTIAL / COMPLETED classification cannot be
assigned under the F1 classifier.

### Derivation

Each of the three determinate classifications requires complete relevant knowledge.

Therefore failure of the knowledge-completeness condition excludes all three.

The remaining canonical immediate classification is:

INDETERMINATE.

### Result

PROVED

### Evidence Type

FORMAL-DERIVATION
