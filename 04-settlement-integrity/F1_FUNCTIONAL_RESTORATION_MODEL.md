# F1 — Functional Restoration Model

## Purpose

Functional restoration describes return of an operational or economic function.

It is not historical restoration and not continuity preservation.

---

## Functional Predicate

Let:

Phi_f(X_t)

represent satisfaction of required functional property f.

Functional restoration occurs when:

Phi_f(X_t) = true

after a prior state in which:

Phi_f(X_k) = false.

---

## Examples

- account again usable,
- settlement pathway operational,
- balance sufficient,
- asset transferable,
- obligation processing resumed.

---

## Separation

FunctionalRestoration
does not imply
ResidualResolution.

FunctionalRestoration
does not imply
HistoricalIntegrity.

FunctionalRestoration
does not imply
ContinuityPreserved.

A system can function again while retaining:

- unresolved residual divergence,
- broken historical continuity,
- remediation history,
- reconstructed state.
