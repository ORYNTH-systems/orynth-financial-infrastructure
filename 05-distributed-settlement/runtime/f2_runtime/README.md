# F2 Reference Runtime

This directory contains the deterministic reference implementation for:

FIN-F2-10 — Executable Reference Implementation

Implemented semantic surfaces:

- authority completeness
- consensus classification
- distributed admissibility
- atomicity classification
- settlement finality classification
- reconciliation classification
- distributed continuity classification
- append-oriented in-memory evidence trace

## Non-Claims

This runtime is not claimed to be:

- production ready
- institution specific
- bank specific
- blockchain specific
- cryptographically immutable
- persistent
- Byzantine-fault-tolerant
- legally authoritative
- universally correct for every settlement system

Formal proof remains separate from runtime conformance.

Adversarial runtime verification belongs to FIN-F2-11.
