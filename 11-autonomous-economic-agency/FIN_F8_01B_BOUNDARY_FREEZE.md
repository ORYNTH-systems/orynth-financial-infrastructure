# FIN-F8-01B — Autonomous Economic Agency / Machine Financial Authority Boundary Freeze

Status: COMPLETE — PASS

## Canonical family

Autonomous Economic Agency and Machine Financial Authority

## Frozen problem boundary

F8 governs the distinction between autonomous or machine financial action capability and the authority required to bind consequential economic action to a valid principal.

The primary F8 question is not whether an autonomous system can select, initiate, route, sign, invoke, settle, trade, purchase, transfer, or otherwise complete a financial action.

The primary question is whether the autonomous action remains attributable to a valid economic principal and supported by current, scoped, temporally valid, non-revoked authority.

## Frozen core separation

autonomous capability != economic principal authority

Autonomous action capability, model output, agent planning, tool access, wallet control, account access, key possession, programmable execution, persistent operation, or successful machine execution SHALL NOT by itself constitute economic principal authority.

## Frozen principal-authority boundary

Machine financial authority MUST be attributable to a valid external or previously admitted economic principal unless a later canonical rule explicitly establishes a valid principal relation.

An autonomous system MUST NOT self-create, self-extend, self-renew, or self-expand economic principal authority merely because it can act independently, retain state, access tools, control credentials, or complete financial operations.

Delegated machine authority MUST remain source-bound, scoped, temporally valid, non-revoked, and attenuated relative to its parent authority.

Autonomous subdelegation MUST NOT amplify authority beyond the delegating principal or parent authority.

## Frozen identity rule

Machine identity, agent identity, account identity, wallet identity, key identity, and economic principal identity MUST remain independently representable.

Possession or control of an identity-bearing technical object MUST NOT constitute principal status.

## Frozen persistence rule

Persistent execution capability MUST NOT be interpreted as persistent authority.

Authority MUST remain subject to current scope, temporal validity, revocation, supersession, and principal continuity.

## Cross-family inheritance

F8 inherits F7 jurisdictional authority boundaries without treating technical reach as principal authority.

F8 inherits F6 programmable-finance authority boundaries without treating automation or executable code as principal authority.

F8 inherits F5 cryptographic-authority boundaries without treating key possession, signature validity, wallet control, or custody capability as principal authority.

F8 inherits F2 multiparty authority distinctions without treating consensus or collective machine action as principal authority.
